۵ تست واحد ذخیره‌سازی پاس شد. بررسی HTTP شامل زبان و جهت، اسکیل‌ها، اعتبارسنجی برند، CSRF، Host، دسترسی فایل و نبود endpoint انتشار پاس شد. آزمون واقعی UI شامل ثبت، جداسازی برند، دو تأیید، ویرایش و ابطال، جست‌وجو، export و ماندگاری پس از restart پاس شد. داده‌های آزمایشی جدا از پنل تحویلی در work ذخیره شدند؛ پنل تحویلی خالی از محتوای تست است.

خطاهای دیده‌شده و رفع‌شده: خطای TLS ابزار Windows با دریافت معتبر از urllib موجود حل شد؛ اولین فرمان نصب مسیر skills/skills داشت و بدون نصب خاتمه یافت، سپس با فهرست صریح ۱۷ مسیر اجرا شد. اتصال SQLite باید پس از transaction بسته می‌شد؛ اصلاح شد. runtime مرورگر Playwright فایل browser bundled نداشت؛ Chrome موجود استفاده شد، بدون نصب مرورگر. انتظارهای آزمون dialog و readiness سرور اصلاح شدند؛ نتیجه نهایی آزمون گردش کار PASS است.

این آزمون‌ها نصب، پنل و دفتر تأیید را تأیید می‌کنند؛ کارکرد providerها، اتصال شبکه‌های اجتماعی، عملکرد SEO و شباهت لحن شخصی را اثبات نمی‌کنند.

راه‌انداز: سرور پنل با pythonw.exe اجرا و endpoint آن تأیید شد. بازکردن مرورگر پیش‌فرض با Start-Process در sandbox خطای Access is denied داد؛ بنابراین بازکردن مرورگر توسط فایل VBS از داخل این محیط تأیید نشده است. نشانی مستقیم پنل در دسترس است و درخواست نمایش آن با ابزار رسمی Codex ثبت شد. بازکردن رابط توسط Chrome در آزمون‌های headless موفق بود.
