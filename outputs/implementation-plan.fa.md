# برنامه پنل محلی

مبنا: master-prompt.fa.md و انتخاب صریح کاربر برای نصب ۱۷ اسکیل و پنل محلی بدون تغییر سرویس موجود.

معماری: Python استاندارد و SQLite، فایل‌های HTML/CSS/JS بدون نصب وابستگی. اجرا فقط روی 127.0.0.1:8766. سرویس‌های GrowthOS تغییر نمی‌کنند. این نسخه، دفتر کار و بسته دستور اسکیل است؛ تولید، تدوین و انتشار خودکار تا اتصال واقعی قابل ادعا نیست.

ساختار: panel/store.py ذخیره و قواعد؛ panel/server.py مسیرهای HTTP؛ panel/index.html و app.js و style.css رابط؛ panel/skills.json نگاشت؛ brands هویت مستقل؛ content-policy.fa.md سیاست مشترک.

- [x] بررسی فایل‌های واقعی ۱۷ اسکیل و Audit سیستم قابل‌دسترسی.
- [x] ثبت پاسخ‌های موجود و موارد واقعاً نامعلوم؛ دو برند مستقل.
- [x] نصب نسخه ثابت با helper و تأیید hash همه فایل‌ها.
- [x] آزمون تفکیک برند، ویرایش بعد تأیید، تأیید قدیمی، تکرار عملیات و ماندگاری.
- [x] پیاده‌سازی دفتر محتوا، تأیید سناریو/انتشار و تاریخچه.
- [x] ساخت رابط فارسی با بسته دستور قابل کپی برای هر اسکیل؛ بدون اجرای خودکار خارجی.
- [x] بررسی HTTP، ذخیره پایدار، رابط و گزارش نتیجه.

ریسک‌های آزمون: XSS در متن کاربر؛ پذیرش درخواست از سایت دیگر؛ تأیید نسخه اشتباه؛ نشت محتوا میان برندها؛ دسترسی فایل خارج از مسیر مجاز. خروجی و backup شامل محتوای شخصی است ولی نباید Secret داشته باشد.

مرحله بعد مستقل: Audit کامل WSL و اتصال تولید/صوت/انتشار و Analytics با credential امن. ساخت این مرحله در وضعیت فعلی نامعلوم گزارش می‌شود.
