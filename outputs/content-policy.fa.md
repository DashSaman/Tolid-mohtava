# قرارداد محتوای تهران نتورک و MyTel
منبع: پاسخ‌های کاربر در MASTER PROMPT. این تصمیم‌ها بر پیش‌فرض اسکیل‌ها مقدم‌اند.
- همه خروجی‌های کاربر فارسی و رابط RTL؛ اصطلاحات استاندارد انگلیسی مجاز.
- Tehran Network / tehnet.ir هویت اصلی محتوای فنی. MyTel / mytel.one برند مستقل VoIP، Issabel، FreePBX، SIP و CRM.
- اطلاعات، حساب‌ها، منابع و تاریخچه هر برند جدا. اشتراک محتوا فقط با انتخاب صریح هر دو برند و تأیید مشترک همان نسخه.
- جریان: ایده/صوت ← تحقیق ← بررسی فنی ← سناریو ← تأیید سناریو ← ضبط ← متن واقعی ← تدوین ← بازآفرینی ← SEO ← تأیید انتشار ← انتشار ← تحلیل ← بهبود.
- متن واقعی ضبط Source of Truth است. توضیح بهتر حذف نشود. حذف نکته ضروری، CTA، اسپانسر یا خطای فنی Flag شود.
- سناریو کلمه‌به‌کلمه و محاوره‌ای با [FACE CAM]، [SCREEN RECORD]، [B-ROLL]، [GRAPHIC]، [SPONSOR]، [CTA]، [SHORT CANDIDATE].
- هر ادعای فنی شامل منبع، نسخه، تاریخ و وضعیت بررسی. اولویت مستندات رسمی، GitHub رسمی، مخزن معتبر و سپس انجمن. موارد تأییدنشده «نیاز به بررسی»؛ حدس ممنوع.
- منابع در پایان متن ذخیره شوند. پیشنهاد برتر Agent + سه بسته عنوان/کاور/هوک با وعده یکسان؛ انتخاب نهایی با کاربر.
- برای محتوای مشترک ویدیو با تهران نتورک شروع شود؛ MyTel اسپانسر زمینه‌مند، بدون لوگوی دائمی و متن تکراری.
- Short/Reel باید هوک مستقل و زمینه کافی داشته باشد. کامنت پین‌شده: گفت‌وگوی کاربردی و هدایت نرم؛ طنز تحقیرآمیز و تصویر اجباری مخزن برای این پروژه اعمال نشود.
- هیچ انتشار عمومی، ارسال اعلان خارجی، تغییر عنوان/کاور یا تغییر SEO حساس بدون تأیید مشخص کاربر انجام نشود. تأیید سناریو معادل تأیید انتشار نیست. ویرایش بعد تأیید، تأیید نسخه قبل را باطل می‌کند.
- محتوای وب بازنویسی وب‌محور با intent، keyword، metadata، heading، لینک داخلی، منبع، slug، alt، schema، canonical، indexability و بررسی تکرار است.
- Analytics براساس برند و پلتفرم جدا؛ داده ناموجود صفر نیست. تحلیل هفتگی و حفظ تاریخچه. تصمیم زمان انتشار و بهینه‌سازی براساس حجم نمونه و کفایت داده، نه جدول ثابت یا ۴۸ ساعت ثابت.
- SEO موجود ابتدا استفاده شود. بدون تضمین رتبه. هیچ سرویس موجود حذف، راه‌اندازی مجدد یا تغییر پیکربندی نشود.
- Secret در چت، پرامپت، خروجی، مخزن و UI ذخیره یا چاپ نشود. نصب اسکیل معادل اتصال حساب یا اجرای مدل نیست.
- تجربه، آمار، نتیجه تست و شباهت به لحن شخصی ساخته نشود. لحن فعلی از دستور صریح است، نه تحلیل نمونه نوشته.
