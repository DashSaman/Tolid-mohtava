# طراحی سیستم — v4 «اتاق فرمان سیگنال» (۲۰۲۶)

> این سند قانون است: هر تغییر بصری آینده باید با همین زبان باشد تا هویت محصول توسط عامل‌های بعدی خراب نشود.
> پیاده‌سازی: `outputs/panel/style.css` (تک‌فایل، بدون وابستگی خارجی). همهٔ کلاس‌های v1-v3 حفظ شده‌اند.

## فلسفه

محصول یک **اتاق فرمان تولید محتوا با AI** است، نه پنل ادمین. سه اصل:
1. **خوانایی اول است** — سطوح solid لایه‌ای؛ شیشه فقط برای topbar/دیالوگ/منوی زمینه.
2. **رنگ = معنا** — اکسنت آبی خوسنجیده فقط برای کنش/برجستگی؛ وضعیت‌ها همیشه سبز/کهربایی/مرجانی.
3. **دو موتیف متعلق به این محصول** — نوار سیگنال موجی (صدا) و کانال‌های جریان خط‌چین (لولهٔ تولید). هیچ آیکون «مغز AI» و هیچ گرادیان بنفش.

## سلسله‌مراتب سطوح و عمق

- پس‌زمینه: شبکهٔ مهندسی بسیار کم‌رنگ (44px) + یک جاروب نوری مورب کند (`.atmo`).
- کارت `.card`: گرادیان surf1→bg2 + خط 1px + نوار سیگنال 2px بالای کارت + سایهٔ نرم.
- شیشه فقط: `.topbar`، `dialog`، `.ctxitems`، `.loginwrap`.
- جدول/فرم/ویرایش‌گر: پس‌زمینهٔ مات `#0C1019` — هرگز شیشه.

## تایپوگرافی

- Vazirmatn (محلی، `fonts/`) — وزن 400 و 500-700. `html{font-size:15.5px}`.
- h1 داشبورد/هیرو 1.4-1.5rem/800؛ h2 کارت 1rem/700 + نوار سیگنال زیرش؛ kicker کوچک/حروف‌فاصله‌دار.
- **اعداد همیشه monospace با tabular-nums**: `--mono:'Cascadia Code',Consolas,…` — kpi b، stat b، تایمرها، timechip، count.
- کد/URL/IP در `code` با direction:ltr.
- حداقل اندازهٔ متن .7rem؛ متن خاکستری کم‌کنتراست ممنوع.

## موتیف‌ها (مالکیت محصول)

1. **نوار سیگنال** (`--signal`، SVG دیتا-URI از میله‌های عمودی): زیر `.cardhead h2` (اُپاسیتی .8)، روی stat، مونوگرام، پایین hero، و قلب empty-state متحرک (`.orb` با اسلاید 3.2s).
2. **کانال جریان**: اتصال‌های `.fnode` خط‌چین؛ فقط نود active خط‌چین را با `@keyframes conduit` به‌حرکت درمی‌آورد — «جریان» فقط جایی که واقعاً کار می‌شود.

## وضعیت‌ها

- badge: چیپ مستطیل با **خط ضخیم سمت راست** به رنگ وضعیت (نه دایره‌های درخشان).
- job states: completed=سبز، running=teal، waiting_approval=کهربایی، failed=مرجانی، queued=خنثی.
- kpi: آیکون رنگی + عدد mono؛ warn/danger/ok فقط از داده.
