# دسترسی راه‌دور امن (Remote Access) — Tolid-Mohtava

> معماری: اینترنت → شبکهٔ خصوصی Tailscale → همین کامپیوتر مجاز → پنل محلی.
> **هیچ پورت‌فوروارد عمومی، DMZ، 0.0.0.0، تانل عمومی Cloudflare/ngrok استفاده نمی‌شود.**
> پنل همیشه روی `127.0.0.1` می‌ماند؛ `tailscale serve` فقط برای دستگاه‌های تأییدشدهٔ tailnet شما پروکسی می‌کند.

## شروع سریع (پس از یک‌بار راه‌اندازی)

1. دوبار کلیک روی **`Open-Panel-Remote.cmd`** — همین. این فایل:
   - پنل را در صورت خاموش بودن بالا می‌آورد؛
   - **پورت واقعی** را خودش پیدا می‌کند (8766 یا fallback ‏8767/8768 — با تأیید `/api/session`، پس سرویس خارجیِ روی 8766 با پنل اشتباه گرفته نمی‌شود)؛
   - اگر احراز هویت فعال نباشد، دستور فعال‌سازی را نشان می‌دهد و **دسترسی راه‌دور را باز نمی‌کند**؛
   - `tailscale serve` را روی همان پورت واقعی تنظیم/به‌روزرسانی می‌کند؛
   - نشانی خصوصی `https://<نام‌کامپیوتر>.<tailnet>.ts.net` را چاپ و باز می‌کند.

## پیش‌نیاز یک‌بار: فعال‌سازی ورود (ADMIN)

دسترسی راه‌دور **تا وقتی رمز تعیین نکنید عمداً قفل است**. برای فعال‌سازی در PowerShell:

```powershell
[Environment]::SetEnvironmentVariable('ADMIN_USER','نام‌کاربری-شما','User')
[Environment]::SetEnvironmentVariable('ADMIN_PASSWORD','رمز-قوی-شما','User')
```

سپس پنل را ببندید (پنجرهٔ کنسول) و `Open-Panel-Remote.cmd` را دوباره اجرا کنید.
رمز در فایل/لاگ/گیت ذخیره نمی‌شود؛ فقط در متغیر محیطی کاربر می‌ماند. نشست ورود ۱۲ ساعت اعتبار دارد و تلاش ناموفق مکرر محدود می‌شود.

## Tailscale

- نصب رسمی (انجام‌شده): `winget install Tailscale.Tailscale` — نسخهٔ 1.102.4، بدون نیاز به ری‌استارت.
- ورود: از منوی Try Tailscale یا نشانی‌ای که اسکریپت باز می‌کند (login.tailscale.com) — با همان اکانت Google/GitHub خودتان.
- وضعیت: آیکن Tailscale در System tray سبز = متصل. این کامپیوتر در tailnet شما: `amirreza-pc` (100.87.126.12).
- در گوشی/لپ‌تاپ دیگر: اپ Tailscale را نصب و **با همان اکانت** وارد شوید؛ سپس همان نشانی `ts.net` را باز کنید.

## ورود از موبایل/لپ‌تاپ

1. Tailscale متصل (هر دو طرف).
2. مرورگر → نشانی خصوصی چاپ‌شده (مثل `https://amirreza-pc.<tailnet>.ts.net`).
3. صفحهٔ ورود پنل: همان `ADMIN_USER/ADMIN_PASSWORD` → ۱۲ ساعت نشست.
4. همهٔ امکانات مثل локال؛ فقط انتشارهای بیرونی مثل همیشه به تأیید شما نیاز دارند.

## اگر پورت عوض شد (8766↔8767)

هیچ کاری لازم نیست — `Open-Panel-Remote.cmd` هر بار پورت واقعی را تشخیص می‌دهد و `serve` را به‌روزرسانی می‌کند. فقط همین فایل را اجرا کنید.

## اگر Tailscale قطع بود

- اسکریپت پیام «ورود به Tailscale» می‌دهد و نشانی ورود را باز می‌کند؛ پس از اتصال، دوباره اجرا کنید.
- پنل محلی (127.0.0.1) مستقل از Tailscale کار می‌کند.

## قطع/غیرفعال‌کردن دسترسی راه‌دور

```powershell
tailscale serve off      # حذف پروکسی (پنل فقط لوکال می‌ماند)
tailscale down           # قطع کامل شبکهٔ خصوصی
```
یا از منوی Tailscale گزینهٔ Disconnect. برای حذف کامل: Uninstall از Settings → Apps.

## نکات امنیتی این پیاده‌سازی

- پنل فقط روی loopback گوش می‌دهد؛ افشای عمومی ممکن نیست.
- `tailscale serve` بدون Funnel = فقط tailnet شما؛ اینترنت عمومی به آن نمی‌رسد.
- دفاع Host-whitelist پنل: فقط `127.0.0.1/localhost` و دامنه‌های `.ts.net` پذیرفته می‌شوند (دفاع DNS-rebinding حفظ شده — تست‌شده).
- CSRF فقط با قاعدهٔ same-origin (لوکال یا `.ts.net`) باز شده — تست ماتریس ۷/۷.
- بدون احراز هویت، `serve` فعال نمی‌شود (دروازهٔ امنیتی خودکار).
- فایروال دست‌نخورده؛ هیچ inbound rule جدیدی ساخته نشده.

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| «احراز هویت ADMIN فعال نیست» | دو متغیر بالا را تنظیم + ری‌استارت پنل |
| نشانی ts.net باز نمی‌شود | Tailscale دو طرف متصل؟ `tailscale status` را ببینید |
| 403 در پنل راه‌دور | از نشانی ts.net باز کرده‌اید (نه IP)? نشست منقضی؟ دوباره وارد شوید |
| پنل بالا نمی‌آید | `Open-Panel.cmd` را بزنید؛ لاگ در پنجرهٔ کنسول |
