# دسترسی راه‌دور امن (Remote Access) — Tolid-Mohtava

> معماری: اینترنت → شبکهٔ خصوصی Tailscale → همین کامپیوتر مجاز → پنل محلی.
> **هیچ پورت‌فوروارد عمومی، DMZ، 0.0.0.0، تانل عمومی Cloudflare/ngrok استفاده نمی‌شود.**

## دو حالت پشتیبانی‌شده (انتخاب خودکار)

| | حالت ۱ (ترجیحی) | حالت ۲ (جایگزین — فعال فعلی) |
|---|---|---|
| نام | Tailscale Serve (HTTPS خصوصی) | IP خصوصی Tailscale + احراز ADMIN |
| نشانی | `https://amirreza-pc.tailacc3b5.ts.net` | `http://100.87.126.12:8767` (IP از `tailscale ip -4` — پویا) |
| پیش‌نیاز | کلید HTTPS Certificates در کنسول Tailscale (صفحهٔ DNS) | هیچ — همیشه آماده |
| رمزنگاری | TLS (گواهی Let's Encrypt از Tailscale) | رمزنگاری لایهٔ انتقال توسط خود tailnet (**HTTP است، نه HTTPS**) |
| عمومی؟ | خیر — فقط tailnet | خیر — فقط tailnet (100.64.0.0/10، پروکسی فقط به همین IP می‌نشیند) |

`Open-Panel-Remote.cmd` خودش بهترین حالتِ موجود را انتخاب می‌کند (اول Serve، بعد جایگزین) — لازم نیست بدانید کدام فعال است. هر بار اجرا، پورت واقعی پنل و IP فعلی Tailscale را داینامیک پیدا می‌کند.

## حالت نهایی (اعتبارنامهٔ ADMIN خودکار ساخته شده)

- حساب ادمین: **tolid-admin** — رمز تصادفی قوی تولید و فقط در این فایل محلی ذخیره شده:
  `%USERPROFILE%\Documents\Tolid-Mohtava-Admin-Credentials.txt` (سطح دسترسی: فقط کاربر ویندوز شما + SYSTEM؛ پس از انتقال به مدیر رمز، فایل را حذف کنید).
- در رجیستری فقط **hash** ‏PBKDF2 رمز نگه‌داری می‌شود (`ADMIN_PASSWORD_HASH`)، نه خود رمز.
- پنل همچنان فقط روی `127.0.0.1` است؛ دسترسی راه‌دور فقط از مسیر Tailscale Serve خصوصی.

## دسترسی روزمره

- **لوکال:** `Open-Panel.cmd`
- **راه‌دور:** `Open-Panel-Remote.cmd` (پنل را بالا می‌آورد، پورت واقعی را می‌یابد، auth را چک می‌کند، Serve را تنظیم و URL خصوصی را باز می‌کند)

## اگر پورت 8766 اشغال باشد

مشکلی نیست — سرویس بیرونیِ روی 8766 (AutoClaw) از روی پاسخ `/api/session` تشخیص داده و رد می‌شود؛ پنل خودکار روی 8767 می‌نشیند و Serve همان پورت واقعی را دنبال می‌کند.

## چرا پنل روی localhost می‌ماند

مرز امنیتی طراحی همین است: فرایند پنل هرگز به کارت شبکه وصل نیست؛ تنها دروازه، پروکسی خصوصی Tailscale است که فقط به دستگاه‌های تأییدشدهٔ tailnet شما سرویس می‌دهد. **Funnel باید همیشه خاموش بماند** (با Funnel، اینترنت عمومی به URL می‌رسد).

## قطع دسترسی / خروج

- خروج از پنل: دکمهٔ خروج در پنل (نشست ۱۲ ساعته).
- قطع پروکسی خصوصی: `tailscale serve off`
- قطع کل شبکهٔ خصوصی: `tailscale down` (یا Disconnect در منوی Tailscale)

## شروع سریع (پس از یک‌بار راه‌اندازی)

1. دوبار کلیک روی **`Open-Panel-Remote.cmd`** — همین. این فایل:
   - پنل را در صورت خاموش بودن بالا می‌آورد؛
   - **پورت واقعی** را خودش پیدا می‌کند (8766 یا fallback ‏8767/8768 — با تأیید `/api/session`، پس سرویس خارجیِ روی 8766 با پنل اشتباه گرفته نمی‌شود)؛
   - اگر احراز هویت فعال نباشد، دستور فعال‌سازی را نشان می‌دهد و **دسترسی راه‌دور را باز نمی‌کند**؛
   - `tailscale serve` را روی همان پورت واقعی تنظیم/به‌روزرسانی می‌کند؛
   - نشانی خصوصی `https://<نام‌کامپیوتر>.<tailnet>.ts.net` را چاپ و باز می‌کند.

## پیش‌نیاز یک‌بار: فعال‌سازی ورود (ADMIN)

دسترسی راه‌دور **تا وقتی رمز تعیین نکنید عمداً قفل است**. برای فعال‌سازی در PowerShell:

```powershell
[Environment]::SetEnvironmentVariable('ADMIN_USER','نام‌کاربری-شما','User')
[Environment]::SetEnvironmentVariable('ADMIN_PASSWORD','رمز-قوی-شما','User')
```

سپس پنل را ببندید (پنجرهٔ کنسول) و `Open-Panel-Remote.cmd` را دوباره اجرا کنید.
رمز در فایل/لاگ/گیت ذخیره نمی‌شود؛ فقط در متغیر محیطی کاربر می‌ماند. نشست ورود ۱۲ ساعت اعتبار دارد و تلاش ناموفق مکرر محدود می‌شود.

## Tailscale

- نصب رسمی (انجام‌شده): `winget install Tailscale.Tailscale` — نسخهٔ 1.102.4، بدون نیاز به ری‌استارت.
- ورود: از منوی Try Tailscale یا نشانی‌ای که اسکریپت باز می‌کند (login.tailscale.com) — با همان اکانت Google/GitHub خودتان.
- وضعیت: آیکن Tailscale در System tray سبز = متصل. این کامپیوتر در tailnet شما: `amirreza-pc` (100.87.126.12).
- در گوشی/لپ‌تاپ دیگر: اپ Tailscale را نصب و **با همان اکانت** وارد شوید؛ سپس همان نشانی `ts.net` را باز کنید.
- **فعال‌سازی حالت ۱ (اختیاری، فقط اگر HTTPS می‌خواهید):** در [صفحهٔ DNS کنسول](https://login.tailscale.com/admin/dns) کلید **HTTPS Certificates** را روشن و **Save** کنید؛ سپس `Open-Panel-Remote.cmd` را دوباره اجرا کنید — خودش به حالت Serve (آدرس ts.net) می‌رود. تا آن زمان حالت ۲ (IP خصوصی) کاملاً امن و فعال است.
- **قطع حالت ۲:** پنجرهٔ پروکسی را ببندید (یا فرایند python مربوط به `tailscale_proxy.py` را پایان دهید) و برای حذف قاعدهٔ فایروال باریک: `Remove-NetFirewallRule -DisplayName 'Tolid-Mohtava-Tailnet-Only'` (نیازمند ادمین).

## موبایل (خلاصهٔ ۴ مرحله‌ای)

```
PHONE:
1. نصب اپ رسمی Tailscale (App Store / Google Play)
2. ورود با همان اکانت tailnet (همان که amirreza-pc به آن وصل است)
3. باز کردن نشانی خصوصی: https://amirreza-pc.<tailnet>.ts.net
4. ورود با حساب ADMIN پنل (ADMIN_USER / ADMIN_PASSWORD)
```
قطع دسترسی خصوصی هر وقت خواستید: روی کامپیوتر `tailscale serve off` (یا Disconnect از منوی Tailscale) — پنل بلافاصله فقط-لوکال می‌شود. تست فیزیکی موبایل: **USER ACTION REQUIRED** (بر عهدهٔ شما).

## ورود از موبایل/لپ‌تاپ

1. Tailscale متصل (هر دو طرف).
2. مرورگر → نشانی خصوصی چاپ‌شده (مثل `https://amirreza-pc.<tailnet>.ts.net`).
3. صفحهٔ ورود پنل: همان `ADMIN_USER/ADMIN_PASSWORD` → ۱۲ ساعت نشست.
4. همهٔ امکانات مثل локال؛ فقط انتشارهای بیرونی مثل همیشه به تأیید شما نیاز دارند.

## اگر پورت عوض شد (8766↔8767)

هیچ کاری لازم نیست — `Open-Panel-Remote.cmd` هر بار پورت واقعی را تشخیص می‌دهد و `serve` را به‌روزرسانی می‌کند. فقط همین فایل را اجرا کنید.

## اگر Tailscale قطع بود

- اسکریپت پیام «ورود به Tailscale» می‌دهد و نشانی ورود را باز می‌کند؛ پس از اتصال، دوباره اجرا کنید.
- پنل محلی (127.0.0.1) مستقل از Tailscale کار می‌کند.

## قطع/غیرفعال‌کردن دسترسی راه‌دور

```powershell
tailscale serve off      # حذف پروکسی (پنل فقط لوکال می‌ماند)
tailscale down           # قطع کامل شبکهٔ خصوصی
```
یا از منوی Tailscale گزینهٔ Disconnect. برای حذف کامل: Uninstall از Settings → Apps.

## نکات امنیتی این پیاده‌سازی

- پنل فقط روی loopback گوش می‌دهد؛ افشای عمومی ممکن نیست.
- `tailscale serve` بدون Funnel = فقط tailnet شما؛ اینترنت عمومی به آن نمی‌رسد.
- دفاع Host-whitelist پنل: فقط `127.0.0.1/localhost` و دامنه‌های `.ts.net` پذیرفته می‌شوند (دفاع DNS-rebinding حفظ شده — تست‌شده).
- CSRF فقط با قاعدهٔ same-origin (لوکال یا `.ts.net`) باز شده — تست ماتریس ۷/۷.
- بدون احراز هویت، `serve` فعال نمی‌شود (دروازهٔ امنیتی خودکار).
- فایروال دست‌نخورده؛ هیچ inbound rule جدیدی ساخته نشده.
