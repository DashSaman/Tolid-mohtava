# کتاب راهنمای اپراتور (OPERATOR RUNBOOK) — v1.0.0-local-ready

> راهنمای کوتاه و عملی برای راه‌اندازی، استفاده و رفع اشکال. فارسی و بدون پیش‌نیاز فنی.

## روشن‌کردن

1. اگر با هوش مصنوعی کار می‌کنید: اول **LM Studio** را باز کنید و مطمئن شوید سرور محلی آن روی `http://127.0.0.1:1234` روشن است و مدل `qwen2.5-7b-instruct` لود شده است.
2. دوبار کلیک روی **`Open-Panel.cmd`** ← مرورگر روی `http://127.0.0.1:8766` باز می‌شود.
3. اگر پنجرهٔ خطای «پورت اشغال است» دیدید: پنل خودکار روی **8767** بالا می‌آید؛ همان نشانی‌ای را که مرورگر باز کرده است ببینید (launcher خودش آدرس درست را باز می‌کند).

**پورت‌ها:** حالت عادی `8766` · اگر سرویس دیگری آن را گرفته باشد `8767` (و در حالت خیلی نادر، 8768). پنل فقط روی همین کامپیوتر (loopback) در دسترس است؛ هرگز پورت را به بیرون باز نکنید.

## خاموش‌کردن امن

- پنجرهٔ کنسول سرور را ببندید (یا `Ctrl+C`).
- کارهای نیمه‌کاره از بین نمی‌روند: با اجرای بعدی، کارهای قطع‌شده به‌صورت صادقانه «ناموفق» ثبت می‌شوند و از صفحهٔ کارها قابل «تلاش دوباره»اند.
- قبل از خاموشیِ طولانی، پشتیبان بگیرید (پایین).

## بررسی سلامت

- در پنل: صفحهٔ **«خدمات و سلامت»** از منوی کنون (یا داشبورد ← «جزئیات»).
- سبز = سالم · زرد/محدود = با محدودیت کار می‌کند (مثلاً GPU محدود، CPU جایگزین می‌شود) · نیازمند Credential = فقط با کلید واقعی فعال می‌شود.
- ساختار پایه: Python · FFmpeg/FFprobe · faster-whisper · GPU/NVENC · دیتابیس · صف کار · LLM · سئو · انتشار.

## اولین پروژه

1. «+ محتوای جدید» (نوار بالا) ← برند ← «متن / ایده» یا «ضبط صدا» یا «آپلود فایل صوتی».
2. ضبط: میکروفون را انتخاب کنید ← «تست میکروفون» ← «شروع ضبط» ← «پایان ضبط» ← شنیدن پیش‌نمایش ← «تأیید و ادامه» ← عنوان ← «ساخت پروژه و تبدیل به متن».
3. متن خودکار در تب **Transcript**؛ سپس تب **هوش مصنوعی** ← «خط تولید کامل».

## ضبط صدا

- قبل از ضبط حتماً «تست میکروفون» را بزنید؛ باید «میکروفون فعال است» ببینید.
- نوار سطح زیر دکمه‌ها باید با صدای شما تکان بخورد؛ ۶ ثانیه سکوت = هشدار.
- بعد از پایان، پیش‌نمایش صوتی می‌آید؛ «تأیید و ادامه» یا «ضبط مجدد» (نسخه‌دار) یا «حذف ضبط».
- صوت بی‌صدا/خراب به‌صورت INVALID_AUDIO رد می‌شود — این رفتار درست است؛ دوباره ضبط کنید.

## آپلود رسانه

- صفحهٔ پروژه ← تب **رسانه** ← نوع را انتخاب کنید (فیس‌کم/صفحه/صدای جدا/…) ← فایل بدهید (تا ۲۰GB).
- فایل اصلی **تغییرناپذیر** است (sha256 ثبت می‌شود)؛ هیچ تدوینی اصل را خراب نمی‌کند.
- چند تراکم؟ «همگام‌سازی خودکار تراک‌ها»؛ اگر «نیاز به بازبینی» گفت، افست دستی بدهید.

## کارهای ناموفق

- صفحهٔ **کارها** ← ردیف قرمز ← باز کنید ← «تلاش دوباره» (تا ۵ بار) یا «لغو».
- خطای «وابستگی ناموجود» یعنی LM Studio/FFmpeg خاموش است — روشن کنید و دوباره تلاش کنید.
- رندر نهایی پیش از اجرا به **مرکز تأیید** می‌رود؛ آنجا «تأیید» یا «رد» کنید.

## پشتیبان‌گیری

```powershell
powershell -ExecutionPolicy Bypass -File setup\Backup-TolidMohtava.ps1
```
- خروجی: `outputs\backups\tolid-<تاریخ>-<ساعت>\` شامل دیتابیس + تنظیمات + checksum.
- فایل‌های حجیم RAW فقط با سوییچ `-IncludeMedia`.

## بازگردانی پشتیبان

```powershell
powershell -ExecutionPolicy Bypass -File setup\Restore-TolidMohtava.ps1 -From outputs\backups\tolid-20260929-220344
```
- پنل را قبل از بازگردانی ببندید. `-WithMedia` رسانه‌ها را هم برمی‌گرداند.

## آرشیو / حذف پروژه

- فهرست پروژه‌ها ← منوی «⋯» ردیف: **آرشیو** (پیشنهادی؛ همه‌چیز حفظ، فقط از فهرست فعال پنهان) یا **حذف پروژه** (باید کلمهٔ «حذف» را تایپ کنید؛ وابستگی‌ها شمرده می‌شوند).
- پروژه‌های آرشیوشده: دکمهٔ **«نمایش آرشیو»** در صفحهٔ پروژه‌ها ← **«بازگردانی از آرشیو»**.
- پست‌های منتشرشدهٔ بیرونی هرگز حذف نمی‌شوند.

## اتصال سرویس‌های بیرونی

- تنظیمات ← **اتصال حساب‌ها** ← ۱۱ کارت. هر کارت دقیقاً می‌گوید کدام متغیر محیطی لازم است.
- مقدارها را با PowerShell ثبت کنید (راهنمای کامل: [CREDENTIAL-ONBOARDING](CREDENTIAL-ONBOARDING.fa.md)):
  `[Environment]::SetEnvironmentVariable('NAME','value','User')` سپس پنل را دوباره باز کنید.
- «تست اتصال» هر کارت بدون ذخیره/نمایش Secret بررسی می‌کند.

## لاگ‌ها کجاست؟

- لاگ هر کار: صفحهٔ کارها ← بازکردن ردیف ← «گزارش اجرا» (در دیتابیس ذخیره می‌شود).
- لاگ سرور: همان پنجرهٔ کنسولی که Open-Panel باز کرده.
- تاریخچهٔ هر پروژه: تب «تاریخچه» پروژه.

## چه چیزی را حذف نکنید

- `outputs\panel\data\` (دیتابیس و رسانه‌های اصلی — تغییرناپذیر).
- `outputs\backups\` — پشتیبان‌ها.
- `.env` (اگر ساخته‌اید) — هرگز در Git commit نشود.
- فایل‌های RAW منبع؛ حذف آن‌ها برگشت‌ناپذیر است.

## اگر LM Studio خاموش بود

- کارهای هوش مصنوعی با خطای صادقانه «وابستگی ناموجود/BLOCKED_BY_DEPENDENCY» fail می‌شوند؛ LM Studio را باز کنید، سرور محلی (127.0.0.1:1234) را روشن کنید، مدل را لود کنید و در پنل «تلاش دوباره» بزنید. بقیهٔ سیستم (ضبط، تدوین، رندر، سئوی داخلی) مستقل از LLM کار می‌کند.

## اگر GPU شکست خورد

- خودکار به CPU برمی‌گردد (کندتر ولی درست). NVENC نبود؟ رندر با x264 انجام می‌شود.
- در صفحهٔ سلامت وضعیت GPU/NVENC را ببینید؛ برای رفع واقعی، درایور NVIDIA را از سایت رسمی به‌روز کنید (ری‌استارت ویندوز لازم است — خارج از وظایف خودکار سیستم).

## اگر FFmpeg خطا داد

- خطای فارسیِ دقیق در صفحهٔ کارها می‌آید (فایل خراب/بی‌صدا واقعاً رد می‌شود؛ رفتار درست است).
- «FFmpeg» در صفحهٔ سلامت قرمز است؟ نصب را دوباره اجرا کنید: `setup\Setup-TolidMohtava.ps1` (بدون آسیب به داده‌ها).

## اگر پنل باز نشد

1. `Open-Panel.cmd` را دوباره اجرا کنید — اگر 8766 اشغال بود خودکار 8767.
2. پنجرهٔ کنسول چه می‌گوید؟ «Python not found» ← `setup\Setup-TolidMohtava.ps1`.
3. مرورگر نشانی `http://127.0.0.1:8767` را دستی امتحان کنید.
4. هنوز نه؟ بازگردانی تنظیمات از پشتیبان (بالا) یا [DISASTER-RECOVERY](DISASTER-RECOVERY.fa.md).
