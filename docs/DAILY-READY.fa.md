# راهنمای نسخهٔ روزانه — ۱۳ اکتبر ۲۰۲۶

این راهنما وضعیت فعلی را توضیح می‌دهد؛ گزارش‌ها و عکس‌های نسخه‌های قبلی تاریخی هستند.

## شروع

`Start-Tolid-Docker.cmd` را اجرا کنید. پنل: http://127.0.0.1:18767 . نام کاربری و رمز قبلی حفظ شده‌اند. برای این نصب، کد فعال در checkout `tolid-docker` روی شاخهٔ `ready/2026-10-13` است.

رسانه و رندرهای این نصب در `D:\Tolid-Mohtava` نگهداری می‌شوند. دیتابیس زنده داخل volume داکر است؛ آن را از ویندوز باز نکنید. `Backup-Tolid-Docker.cmd` snapshot سالم و SHA256 را در پوشهٔ backups روی D می‌سازد. فایل‌های اصلی قدیمی روی C حذف نشده‌اند. My Passport اختیاری است؛ برای آرشیو باید متصل باشد.

## مسیر استفاده

۱. برند درست را انتخاب و پروژه ایجاد کنید؛ فایل صوت یا متن منبع را اضافه کنید.
۲. تبدیل گفتار و تولید محتوا را اجرا کنید. هوش مصنوعی همین نصب Ollama با qwen3.5:4b است. متن تولیدی و بررسی فنی AI را پیش از تأیید با منابع واقعی بازبینی کنید.
۳. ضبط صفحه یا ویدیو را بارگذاری کنید؛ برش‌های پیشنهادی حذف سکوت و متن را بررسی کنید. RAW تغییر نمی‌کند. پیش‌نمایش، رندر نهایی و Shorts موجودند.
۴. رندر و نسخهٔ محتوا را در مرکز تأیید تأیید کنید. بستهٔ dry-run آمادهٔ بازبینی و انتشار دستی است.
۵. برای بنچمارک، یک صدای کوتاه فارسی آپلود کنید؛ در تنظیمات همان فایل و متن صحیح آن را انتخاب کنید. small و medium مقایسه می‌شوند. مدل large-v3 به دانلود جدا نیاز دارد.

## حساب‌ها و محدودیت‌های واقعی

فقط آماده‌بودن کانال یوتیوب اتصال API ایجاد نمی‌کند. `Connect-YouTube.cmd` راهنمای ثبت Client ID/Secret را دارد؛ در Google Cloud، YouTube Data API v3، OAuth Web client و redirect `http://127.0.0.1:18767/oauth/callback` لازم است. سپس در پنل «اتصال حساب» و «تست اتصال» را انجام دهید. رمز یا کلید را در چت نفرستید.

آپلود YouTube با SDK رسمی گوگل، خصوصی و با تأیید نسخه انجام می‌شود. تا OAuth انجام نشده، آپلود واقعی و آمار کانال قابل آزمون نیست. آمار فعلی، مجموع views/subscribers/videos کانال است؛ retention و watch time تفصیلی پیاده‌سازی نشده‌اند.

WordPress پیش‌نویس واقعی، GSC، GA4 و Gemini به کلید/دسترسی مربوط نیاز دارند؛ بدون آنها وضعیت مسدود نمایش داده می‌شود. Instagram، Facebook و LinkedIn فعلاً بستهٔ انتشار و ثبت دستی آمار دارند؛ افزودن OAuth به‌تنهایی انتشار و ingestion خودکار آنها را فعال نمی‌کند. مدل تصویر محلی جای Gemini در این نسخه نصب نشده است.

ابزار موجود برای حذف سکوت، برش متن، تولید زیرنویس و خروجی آموزشی مناسب است. تدوین معنایی کاملاً خودکار، زوم هوشمند صفحه و ترکیب کامل چند دوربین هنوز قابلیت آمادهٔ این نسخه نیست. بخش همگام‌سازی offset تراک را نگه می‌دارد؛ برای خروجی پیچیده بازبینی دستی لازم است.

## استفاده از پروژه‌های آماده

FFmpeg و faster-whisper موجود، مدل‌های از قبل دانلودشده و Ollama موجود دوباره استفاده شدند. اتصال YouTube بر SDK رسمی گوگل تکیه دارد.

[Auto-Editor](https://github.com/WyattBlue/auto-editor) برای حذف سکوت و خروجی مستقیم کاربرد دارد؛ این قابلیت در پنل موجود است و نصب موازی انجام نشد. [OpenCut-AI](https://github.com/Ekaanth/OpenCut-AI) گزینهٔ بررسی آینده برای تدوین متن و چند دوربین است؛ برای این نصب و فارسی/RTL تأیید نشده و وارد stack فردا نشده است.

۱۶ رکورد رسانه از قبل فایل نداشتند؛ حذف یا بازیابی ساختگی انجام نشده. اگر متعلق به ضبط واقعی‌اند، فایل منبع را دوباره اضافه کنید. خطاهای قدیمی صف نیز برای بررسی حفظ شده‌اند.


## انتقال ذخیره‌سازی Docker در همین نصب

با تأیید مالک، فایل دیسک Docker Desktop در `D:\DockerDesktopData\disk` قرار گرفت؛ مسیر پیشین روی C با junction به همان پوشه هدایت می‌شود. اصل فایلِ قبل از شروع دوباره، پس از تطبیق SHA256، در `D:\DockerDesktopData\rollback-20261013` حفظ شده است. تمام کانتینرهای فعال قبلی راه‌اندازی شدند. این دو پوشه را هنگام کار Docker تغییر ندهید.

اطلاعات ورود قبلی پنل در `Documents\Tolid-Mohtava-Admin-Credentials.txt` روی همین حساب ویندوز است. رمز تغییر نکرده است.
